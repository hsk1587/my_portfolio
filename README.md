# My Portfolio

홍서경의 포트폴리오 메인 페이지입니다. 세 가지 프로젝트를 카드로 소개하고, 카드를 누르면 해당 프로젝트로 이동합니다.

## 소개하는 프로젝트

| 프로젝트 | 설명 | 이동 위치 |
|---|---|---|
| 환율 변환기 | 금액과 통화를 고르면 바로 환율을 계산해 주는 웹페이지 | `../fxconveter/index.html` |
| 스네이크 게임 | 먹이를 먹으며 길어지는 뱀을 조종하는 브라우저 게임 | `../Snake game/index.html` |
| 홍보자동화 | 매장 사진과 홍보 문구를 한 번에 만들어 주는 파이썬 도구 | [GitHub](https://github.com/hsk1587/auto_generate_app) |

각 카드에는 문제, 해결, 결과를 짧게 정리했습니다.

## 디자인

- 큰 세리프(명조) 제목과 흰색 카드 중심의 편집 디자인
- 카드에 마우스를 올리면 살짝 떠오르는 움직임
- 스크롤하면 카드가 부드럽게 나타남
- 휴대폰 화면에서도 보기 좋게 반응형으로 구성

## 파일 구성

```
My-Portfolio/
├── index.html   # 페이지 내용
├── style.css    # 디자인
├── main.js      # 카드가 나타나는 움직임
└── README.md
```

## 보는 방법

`index.html`을 더블클릭하면 브라우저에서 열립니다. 별도 설치는 필요 없습니다.

## 참고

- 환율 변환기와 스네이크 게임 카드는 폴더 안의 상대 경로로 연결돼 있습니다. 두 프로젝트가 이 폴더의 바깥(같은 상위 폴더)에 있어야 이동이 됩니다.
- 이 저장소만 GitHub에 올렸을 때는 위 두 링크가 열리지 않습니다. 각 프로젝트의 공개 주소로 바꾸면 해결됩니다.
- 글꼴(Noto Serif KR, Noto Sans KR)은 Google Fonts에서 불러옵니다.
